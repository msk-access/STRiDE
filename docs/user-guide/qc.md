# Quality Control Reports

STRiDE includes a powerful Quality Control (QC) module designed to help reviewers
differentiate true biological Microsatellite Instability (MSI) from sequencing
artifacts.  Because targeted NGS panels often suffer from alignment artifacts at
homopolymer edges, STRiDE generates an **interactive, expert-level QC dashboard**
directly from the feature TSV produced during prediction.

---

## Requirements

The QC module uses optional plotting dependencies.  Install with the `qc` extra:

```bash
pip install "stride[qc]"
```

This pulls in **Plotly ≥ 5.15** (visualisations) and loads
[Tabulator.js](https://tabulator.info) from a CDN at runtime for the data table
(no local JS build required).

---

## Running the QC Module

### Standalone Command

If you already have a feature TSV (generated by `stride run` or
`stride features`), you can build the QC report independently:

```bash
stride qc \
    --feature-tsv out/features/msi_features_SampleA.tsv \
    --output SampleA_qc.html
```

You can optionally pass the prediction result to populate the **MSI label** and
**MSI Score** in the dashboard hero banner:

```bash
stride qc \
    --feature-tsv out/features/msi_features_SampleA.tsv \
    --prediction out/predictions/SampleA_msi.txt \
    --output SampleA_qc.html
```

### Pipeline Integration

Instruct `stride run` to automatically generate QC reports after prediction
with the `--generate-qc` flag:

```bash
stride run \
    --samples-list batch.csv \
    --out-dir batch_run \
    --generate-qc
```

This creates a `qc/` directory alongside `features/` and `predictions/`
containing one HTML report per sample.

## Report Overview

The HTML report is a **single self-contained file** that opens in any modern
browser.  It is organised into **three tabs**, accessed via the tab bar
immediately below the Hero Banner.

### Hero Banner

The top-level summary strip shows:

| Metric | Description |
|--------|-------------|
| **Prediction** | MSI/MSS/UNKNOWN badge (populated when `--prediction` is supplied) |
| **MSI Score** | Numeric MSI score from the prediction model |
| **Sites** | Total number of microsatellite loci analysed |
| **Threshold** | Decision threshold used by the prediction model (default 0.50) |
| **Theme Toggle** | 🌙/☀ button in the top-right corner; switches the entire report between dark and light mode |

---

## Tab 1 — Dashboard

The Dashboard provides a bird's-eye view of the sample's MSI landscape through
eight interactive Plotly cards.  All figures support pan, zoom, hover tooltips,
and PNG export via the Plotly toolbar.

### 1.1 Instability Waterfalls (full-width, 1 × 3)

Three side-by-side waterfall (rank-ordered bar) charts for **L1 Distance**,
**L2 Distance**, and **Wasserstein Distance**.  Each panel independently ranks
all loci from highest to lowest distance.

- **Interpretation:**
  True MSI samples show a smooth, systemic rise across hundreds of loci.
  False positives driven by a handful of artifact-heavy sites appear as a steep
  cliff in just the first few bars.

### 1.2 Distance Correlation (L1 vs L2)

A scatter plot of L1 Distance (x) against L2 Distance (y) for every locus,
coloured by Wasserstein distance.  A diagonal y = x reference line is drawn.

- **Interpretation:**
  Points far from the diagonal indicate loci where
  L1 and L2 disagree, often flagging distributional shifts driven by outlier
  bins rather than broad instability.

### 1.3 Distance Distributions

Overlapping histograms of all three distance metrics with vertical dashed
mean lines.  Provides a population-level view of how the distances are
distributed across all loci.

### 1.4 Volcano Plots (full-width, 1 × 3)

Three side-by-side volcano plots: **L1**, **L2**, and **Wasserstein** on the
x-axis versus **–log₁₀(p-value)** on the y-axis.  A horizontal dashed line
marks the p = 0.05 significance threshold.

- **Colour coding:**
  - **Green dots** — loci with tumour MapQ ≥ 40 (well-mapped).
  - **Orange ✕** — loci with tumour MapQ < 40 (potential alignment artefact).
- **Interpretation:**
  Genuine MSI loci cluster in the top-right (high distance, high significance).
  Orange crosses indicate sites where the shift may be an alignment artefact.

### 1.5 Entropy Scatter

Normal Entropy vs Tumour Entropy, coloured by Entropy Δ.  A diagonal y = x
line separates loci with entropy gain (above) from entropy loss (below).

- **Interpretation:**
  MSI causes the repeat-length distribution to broaden → higher entropy.
  Loci above the diagonal with large Δ Entropy are strong MSI candidates.

### 1.6 Quality Metrics (Violins)

Split violin plots comparing Normal vs Tumour distributions for **MapQ**,
**Base Quality**, and **log₁₀(Coverage)**.

- **Interpretation:**
  Ensures the two samples have comparable sequencing quality;
  large asymmetries could bias distance calculations.

## Tab 2 — Site Explorer

Drill down into **every individual locus** with an interactive
repeat-length distribution histogram.  Loci are sorted by chromosome and
position.

### Features

| Feature | Description |
|---------|-------------|
| **Searchable Combobox** | Type to filter loci by genomic position (e.g. `chr4:55`); click the dropdown arrow or focus the input to browse the full list |
| **Prev / Next Navigation** | ‹ / › buttons with a counter (e.g. "42 / 170") for sequential browsing |
| **Raw / Normalized Toggle** | Pill-style buttons to swap the Y-axis between normalised frequency (0–1) and raw read counts (integers); state persists across locus changes |
| **Normal vs Tumour bars** | Side-by-side bars; tooltips identify **Normal** or **Tumor** and show both frequency and raw read count |
| **Dynamic X-axis** | Range auto-scales to the maximum observed repeat length across all sites, eliminating wasted whitespace |
| **Reference line** | Green dashed vertical line at the reference repeat count for the selected locus; dynamically adjusts per site |
| **Quality badge** | Styled badge (✓ PASS / ⚠ REVIEW / ⚠ FAIL) based on tumour MapQ and insert-size delta |
| **Stats strip** | L1, L2, Wass, p-value, Entropy Δ, T_Cov, N_Cov, T_MapQ, T_BQ |
| **Legend** | Always visible (Normal / Tumour / Ref) even when switching loci |

## Tab 3 — Data Table

A fully interactive table powered by [Tabulator.js v6](https://tabulator.info)
with the **Midnight dark theme** (auto-switches with the report-wide
light/dark mode toggle).

### Table Features

| Feature | Description |
|---------|-------------|
| **Dynamic height** | Table height fills the viewport (`calc(100vh - 260px)`) so it adapts to any screen size with vertical scrollbar |
| **Horizontal scroll** | Layout mode `fitDataFill` — columns use natural widths; a horizontal scrollbar appears when columns exceed viewport width |
| **Frozen Rank column** | The Rank column is frozen on the left so it remains visible during horizontal scrolling |
| **Progress bar formatters** | L1, L2, and Wasserstein columns display colour-gradient progress bars (green → orange) proportional to the sample-wide maximum; the exact value is overlaid as a legend |
| **Column header filters** | Every column has a built-in filter input in the header row (text or numeric) |
| **Click-to-sort** | Click any column header to sort ascending/descending |
| **Column reordering** | Drag column headers to rearrange |
| **Column resize** | Drag header borders to resize columns |
| **Header text wrapping** | Long header names wrap instead of truncating |
| **Conditional row styling** | Loci with L1 > 70% of the sample maximum get an orange left-border indicator |
| **MapQ warning** | Tumour MapQ values below 40 are rendered in orange bold to flag potential artefacts |
| **Tooltips** | Hover over L1/L2/Wass cells to see the exact numeric value |
| **Pagination** | Page sizes of 25 / 50 / 100 / All; defaults to 50 |
| **CSV download** | Click **⬇ Download CSV** to export the full (filtered) table as a CSV file |

### Columns

| Column | Description |
|--------|-------------|
| Rank | Rank by L1 distance (descending) |
| Chr | Chromosome |
| Start | Genomic start position |
| Unit | Repeat unit motif (e.g. A, T, AC) |
| Count | Reference repeat count |
| L1 | L1 (Manhattan) distance between normal and tumour distributions |
| L2 | L2 (Euclidean) distance |
| Wass. | Wasserstein (Earth Mover's) distance |
| p-value | KS-test p-value for distribution divergence |
| Ent. Δ | Entropy difference (tumour – normal) |
| T_Cov | Tumour total coverage at the locus |
| N_Cov | Normal total coverage at the locus |
| T_MapQ | Mean tumour mapping quality |
| T_BQ | Mean tumour base quality (if available) |

## Interpreting the Report

### Quick Decision Flow

```text
1. Check Hero Banner → known MSI/MSS or UNKNOWN?
2. Dashboard Waterfalls → systemic shift or cliff?
3. Volcano Plots → significant loci well-mapped (green) or artefactual (orange)?
4. Site Explorer → inspect top-ranked loci individually
5. Data Table → filter / search / export for reporting
```

### Red Flags (Potential Artefacts)

- 🔸 Only 1–3 loci with high distance; rest near zero (waterfalls show a cliff)
- 🔸 High-distance loci are all orange (MapQ < 40) in the Volcano plot
- 🔸 Large entropy delta but low coverage
- 🔸 Tumour MapQ noticeably lower than Normal in the Quality Violins

## CLI Reference

| Flag | Context | Description |
|------|---------|-------------|
| `--feature-tsv` | `stride qc` | Path to the feature TSV |
| `--prediction` | `stride qc` | Optional prediction TSV to populate hero banner |
| `--output` | `stride qc` | Output HTML path (default: `qc_report.html`) |
| `--generate-qc` | `stride run` | Auto-generate QC reports after prediction |
| `--verbose` / `-V` | both | Enable debug logging |
